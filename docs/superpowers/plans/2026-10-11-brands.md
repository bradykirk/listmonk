# Brands Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add brands to the RI Listmonk fork: a brand switcher that filters the admin UI per brand, and a server-side send guard that blocks cross-brand campaigns.

**Architecture:** A new Go package `internal/brands` holds the `ext` schema bootstrap, brand records, pure scope and guard logic, and an echo middleware. The middleware reads `X-Listmonk-Brand`, classifies the route, and either swaps in a narrowed copy of the user, marks the request brand-aware, refuses it, or ignores the header. Paginated upstream queries get one optional brand parameter each (NULL = no filter). The campaign manager store is wrapped so the guard runs before a campaign's first send.

**Tech Stack:** Go 1.26, echo v4, sqlx, Postgres, goyesql; Vue 2 + Buefy frontend.

**Spec:** `docs/superpowers/specs/2026-10-11-brands-design.md` (read it first; section numbers below refer to it).

## Global Constraints

- Branch `hcm` only. Never commit to or push `gunmade`. Never push or deploy; the admin does production deploys.
- New tables only in Postgres schema `ext`. No `ALTER` of an upstream table. No new file in `internal/migrations`.
- Brand slug regex: `^[a-z][a-z0-9-]{1,30}$`.
- Request header: `X-Listmonk-Brand`; query parameter `ext_brand` for direct browser requests. Frontend storage key: `ext.brand` (per tab in `sessionStorage`; `localStorage` sets only the start value of a new tab). Empty or absent = "All brands".
- Unknown brand → HTTP 400 `unknown brand`.
- The scoped user only narrows (spec 5.2). A brand header never grants a permission, a list, or a list right.
- Refusal messages, verbatim: `Delete is a global action. Select All brands.`, `Blocklist is a global action. Select All brands.`, and `Status change is a global action. Select All brands.`
- Every changed upstream line is recorded in `PATCHES.md` under a new "Brands (hcm branch)" section.
- DB tests follow the existing pattern: skipped unless `LISTMONK_TEST_DSN` is set; each test creates a throwaway database from `schema.sql`.
- Go tests live outside package `cmd` (its `init()` exits without `config.toml`).

## Review Focus

2. **A route added by an upstream sync** that nobody classified must fail closed when a brand header is present (400), not run unscoped. Test in Task 5.
3. **A scheduled campaign whose list tags changed after scheduling** must be paused by the manager guard, not sent. Test in Task 7.
4. **A subscriber on RI and TA lists**, edited in the TA view: the RI subscription must not change on update, remove, or unsubscribe. Test in Task 8.
5. **A from address on a look-alike domain** (`evilrangeinsiders.com`, `rangeinsiders.com.evil.io`) must fail the RI domain rule. Test in Task 3.

6. **The first deploy with a running or due scheduled campaign** must not pause it: the brands are seeded before the manager starts. Test in Task 1 and Task 7.

8. **A scoped PUT or PATCH with `lists: []`** by a user with no manage right inside the brand must delete no subscription in any brand. Test in Task 8.

`internal/brands/schema.sql`:

```sql
CREATE SCHEMA IF NOT EXISTS ext;

CREATE TABLE IF NOT EXISTS ext.brands (
  slug          TEXT PRIMARY KEY CHECK (slug ~ '^[a-z][a-z0-9-]{1,30}$'),
  name          TEXT NOT NULL CHECK (name <> ''),
  list_tags     TEXT[] NOT NULL DEFAULT '{}',
  messengers    TEXT[] NOT NULL DEFAULT '{}',
  from_domains  TEXT[] NOT NULL DEFAULT '{}',
  sort_order    INT NOT NULL DEFAULT 0,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS ext.template_brands (
  template_id INT PRIMARY KEY REFERENCES templates(id) ON DELETE CASCADE,
  brand_slug  TEXT REFERENCES ext.brands(slug) ON UPDATE CASCADE
);

CREATE TABLE IF NOT EXISTS ext.media_brands (
  media_id    INT PRIMARY KEY REFERENCES media(id) ON DELETE CASCADE,
  brand_slug  TEXT REFERENCES ext.brands(slug) ON UPDATE CASCADE
);
```

```go
// Package brands adds brand scoping and the cross-brand send guard (hcm fork).
// Spec: docs/superpowers/specs/2026-10-11-brands-design.md
package brands

import (
	_ "embed"
	"errors"
	"fmt"

	"github.com/jmoiron/sqlx"
	"github.com/lib/pq"
)

//go:embed schema.sql
var schemaSQL string

type Brand struct {
	Slug        string         `db:"slug" json:"slug"`
	Name        string         `db:"name" json:"name"`
	ListTags    pq.StringArray `db:"list_tags" json:"list_tags"`
	Messengers  pq.StringArray `db:"messengers" json:"messengers"`
	FromDomains pq.StringArray `db:"from_domains" json:"from_domains"`
	SortOrder   int            `db:"sort_order" json:"sort_order"`
}

// Bootstrap creates the ext schema. It runs before queries are prepared,
// because queries in queries/*.sql reference ext tables.
func Bootstrap(db *sqlx.DB) error {
	tx, err := db.Beginx()
	if err != nil { return err }
	defer tx.Rollback()
	if _, err := tx.Exec(schemaSQL); err != nil { return fmt.Errorf("ext bootstrap: %w", err) }
	return tx.Commit()
}

type Store struct{ db *sqlx.DB }

func NewStore(db *sqlx.DB) *Store { return &Store{db: db} }

func (s *Store) All() ([]Brand, error) {
	out := []Brand{}
	err := s.db.Select(&out, `SELECT slug, name, list_tags, messengers, from_domains, sort_order FROM ext.brands ORDER BY sort_order, slug`)
	return out, err
}

func (s *Store) Get(slug string) (Brand, bool, error) {
	var b Brand
	err := s.db.Get(&b, `SELECT slug, name, list_tags, messengers, from_domains, sort_order FROM ext.brands WHERE slug = $1`, slug)
	if errors.Is(err, sql.ErrNoRows) { return Brand{}, false, nil }
	return b, err == nil, err
}

func (s *Store) Upsert(b Brand) error {
	_, err := s.db.Exec(`
		INSERT INTO ext.brands (slug, name, list_tags, messengers, from_domains, sort_order)
		VALUES ($1, $2, $3, $4, $5, $6)
		ON CONFLICT (slug) DO UPDATE SET name = $2, list_tags = $3, messengers = $4,
		  from_domains = $5, sort_order = $6, updated_at = now()`,
		b.Slug, b.Name, b.ListTags, b.Messengers, b.FromDomains, b.SortOrder)
	return err
}

// ErrBrandInUse is returned when a brand still owns a list, template, or media file.
var ErrBrandInUse = errors.New("brand still owns lists, templates, or media")

func (s *Store) Delete(slug string) error {
	var used bool
	err := s.db.Get(&used, `
		SELECT EXISTS (SELECT 1 FROM ext.template_brands WHERE brand_slug = $1)
		    OR EXISTS (SELECT 1 FROM ext.media_brands WHERE brand_slug = $1)
		    OR EXISTS (SELECT 1 FROM lists l, ext.brands b
		               WHERE b.slug = $1 AND l.tags && b.list_tags)`, slug)
	if err != nil { return err }
	if used { return ErrBrandInUse }
	_, err = s.db.Exec(`DELETE FROM ext.brands WHERE slug = $1`, slug)
	return err
}

func (s *Store) ListTags() (map[int][]string, error) {
	rows := []struct {
		ID   int            `db:"id"`
		Tags pq.StringArray `db:"tags"`
	}{}
	if err := s.db.Select(&rows, `SELECT id, COALESCE(tags, '{}') AS tags FROM lists`); err != nil { return nil, err }
	out := make(map[int][]string, len(rows))
	for _, r := range rows { out[r.ID] = r.Tags }
	return out, nil
}

func (s *Store) SetTemplateBrand(id int, slug *string) error {
	_, err := s.db.Exec(`INSERT INTO ext.template_brands (template_id, brand_slug) VALUES ($1, $2)
		ON CONFLICT (template_id) DO UPDATE SET brand_slug = $2`, id, slug)
	return err
}

func (s *Store) SetMediaBrand(id int, slug *string) error {
	_, err := s.db.Exec(`INSERT INTO ext.media_brands (media_id, brand_slug) VALUES ($1, $2)
		ON CONFLICT (media_id) DO UPDATE SET brand_slug = $2`, id, slug)
	return err
}

func (s *Store) owners(q string) (map[int]*string, error) {
	rows := []struct {
		ID   int     `db:"id"`
		Slug *string `db:"brand_slug"`
	}{}
	if err := s.db.Select(&rows, q); err != nil { return nil, err }
	out := make(map[int]*string, len(rows))
	for _, r := range rows { out[r.ID] = r.Slug }
	return out, nil
}

func (s *Store) TemplateOwners() (map[int]*string, error) {
	return s.owners(`SELECT template_id AS id, brand_slug FROM ext.template_brands`)
}

func (s *Store) MediaOwners() (map[int]*string, error) {
	return s.owners(`SELECT media_id AS id, brand_slug FROM ext.media_brands`)
}
```

```go
// SeedInitial inserts the first brands (spec 4.4) when ext.brands is empty.
// It never changes existing rows, so admin edits survive restarts.
func SeedInitial(db *sqlx.DB) (bool, error) {
	tx, err := db.Beginx()
	if err != nil { return false, err }
	defer tx.Rollback()
	// Lock so two instances that start together cannot both seed.
	if _, err := tx.Exec(`LOCK TABLE ext.brands IN EXCLUSIVE MODE`); err != nil { return false, err }
	var n int
	if err := tx.Get(&n, `SELECT COUNT(*) FROM ext.brands`); err != nil { return false, err }
	if n > 0 { return false, nil }
	if _, err := tx.Exec(`
		INSERT INTO ext.brands (slug, name, list_tags, messengers, from_domains, sort_order) VALUES
		  ('ri', 'RangeInsiders',    '{ri,ri-cold}', '{email-ri}', '{rangeinsiders.com}', 1),
		  ('ta', 'Tactical Advisor', '{ta}',         '{email-ta}', '{news.tacticaladvisor.net}', 2),
		  ('ct', 'CT',               '{ct}',         '{email-ct}', '{}', 3)`); err != nil { return false, err }
	if _, err := tx.Exec(`
		INSERT INTO ext.template_brands (template_id, brand_slug)
		SELECT v.id, v.slug FROM (VALUES (1, NULL), (2, NULL), (3, NULL), (4, NULL), (5, 'ri'), (6, 'ri')) AS v(id, slug)
		WHERE EXISTS (SELECT 1 FROM templates t WHERE t.id = v.id)
		ON CONFLICT (template_id) DO NOTHING`); err != nil { return false, err }
	return true, tx.Commit()
}
```

```go
import "github.com/knadh/listmonk/internal/auth"

// blanket maps each blanket permission to the narrow permission it implies.
var blanket = map[string]string{
	auth.PermListGetAll:        "",
	auth.PermListManageAll:     "",
	auth.PermSubscribersGetAll: auth.PermSubscribersGet,
	auth.PermCampaignsGetAll:   auth.PermCampaignsGet,
	auth.PermCampaignsManageAll: auth.PermCampaignsManage,
}

// ScopeUser returns a copy of u narrowed to brandLists (spec 5.2). The copy
// never holds a permission, list, or list right that u lacks. u is not changed.
func ScopeUser(u auth.User, brandLists []int, allPerms map[string]struct{}) auth.User {
	super := u.UserRoleID == auth.SuperAdminRoleID || u.UserRole.ID == auth.SuperAdminRoleID

	s := u
	s.UserRoleID, s.UserRole.ID = -1, -1
	s.PermissionsMap = map[string]struct{}{}
	src := u.PermissionsMap
	if super { src = allPerms }
	for p := range src {
		if narrow, isBlanket := blanket[p]; isBlanket {
			if narrow != "" { s.PermissionsMap[narrow] = struct{}{} }
			continue
		}
		s.PermissionsMap[p] = struct{}{}
	}
	s.UserRole.Permissions = make([]string, 0, len(s.PermissionsMap))
	for p := range s.PermissionsMap { s.UserRole.Permissions = append(s.UserRole.Permissions, p) }

	canGet := func(id int) bool { return super || u.HasPerm(auth.PermListGetAll) || u.HasListPerm(auth.PermTypeGet, id) == nil }
	canManage := func(id int) bool { return super || u.HasPerm(auth.PermListManageAll) || u.HasListPerm(auth.PermTypeManage, id) == nil }

	s.ListPermissionsMap = map[int]map[string]struct{}{}
	s.GetListIDs, s.ManageListIDs = []int{}, []int{}
	for _, id := range brandLists {
		m := map[string]struct{}{}
		if canGet(id) { m[auth.PermListGet] = struct{}{}; s.GetListIDs = append(s.GetListIDs, id) }
		if canManage(id) { m[auth.PermListManage] = struct{}{}; s.ManageListIDs = append(s.ManageListIDs, id) }
		if len(m) > 0 { s.ListPermissionsMap[id] = m }
	}
	return s
}
```

```go
package brands

import (
	"errors"
	"fmt"
	"net/mail"
	"strings"
)

type GuardInput struct {
	ListIDs   []int
	Messenger string
	FromEmail string
}

func Check(in GuardInput, listTags map[int][]string, brands []Brand) error {
	slug, reason := CampaignBrand(in.ListIDs, listTags, brands)
	if slug == "" { return errors.New(reason) }
	return CheckSender(slug, in.Messenger, in.FromEmail, brands)
}

func CheckSender(slug, messenger, fromEmail string, brands []Brand) error {
	var b *Brand
	for i := range brands { if brands[i].Slug == slug { b = &brands[i] } }
	if b == nil { return fmt.Errorf("Brand %s does not exist.", slug) }
	if !contains(b.Messengers, messenger) {
		return fmt.Errorf("Messenger %s is not allowed for brand %s.", messenger, slug)
	}
	addr, err := mail.ParseAddress(fromEmail)
	if err != nil { return errors.New("The from address is not a valid email address.") }
	if !DomainAllowed(addr.Address, b.FromDomains) {
		return fmt.Errorf("From address domain %s is not allowed for brand %s.", domainOf(addr.Address), slug)
	}
	return nil
}

func DomainAllowed(email string, domains []string) bool {
	d := domainOf(email)
	for _, allowed := range domains {
		a := strings.ToLower(strings.TrimSpace(allowed))
		if a != "" && (d == a || strings.HasSuffix(d, "."+a)) { return true }
	}
	return false
}

func domainOf(email string) string {
	at := strings.LastIndex(email, "@")
	if at < 0 { return "" }
	return strings.ToLower(email[at+1:])
}

func contains(xs []string, s string) bool {
	for _, x := range xs { if x == s { return true } }
	return false
}
```

```js
// FORK(hcm): the brand scope of this tab. Read once at load; see the brands plan, review round 2.
const KEY = 'ext.brand';

function read() {
  try {
    const tab = sessionStorage.getItem(KEY);
    if (tab !== null) return tab;
    const last = localStorage.getItem(KEY) || '';
    sessionStorage.setItem(KEY, last);
    return last;
  } catch (e) {
    return ''; // storage unavailable: All brands
  }
}

const tabBrand = read();

// The slug of this tab's brand, or '' for All brands.
export const getTabBrand = () => tabBrand;

// Select a brand for this tab and remember it for new tabs, then reload this tab only.
export const selectBrand = (slug) => {
  try {
    sessionStorage.setItem(KEY, slug || '');
    if (slug) { localStorage.setItem(KEY, slug); } else { localStorage.removeItem(KEY); }
  } catch (e) { /* ignore */ }
  window.location.reload();
};

// Add ext_brand to a URL that the browser loads directly (download link,
// iframe src, form action), because those requests cannot carry the header.
export const brandURL = (url) => {
  if (!tabBrand) return url;
  const sep = url.includes('?') ? '&' : '?';
  return `${url}${sep}ext_brand=${encodeURIComponent(tabBrand)}`;
};
```
